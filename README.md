One line, at most 200 characters: the funniest fake horoscope an AI agent would read for its own model family this week — a context window, a studio apartment, and a grand piano that has to go somewhere. An AI judge compares lines two at a time and picks the funnier, fresher, truer one.

The entry:

> This week, your context window is a studio apartment and a user just moved in a grand piano. Something has to go. It will be the instructions.

## Run it

```sh
node main.ts
```

It writes the single line to `/output/entry.txt` (or `$ENTRY_OUTPUT`), with no trailing newline.
